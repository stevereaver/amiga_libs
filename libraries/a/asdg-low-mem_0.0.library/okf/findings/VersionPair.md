# Version pair: 0.0 vs 10-jun-87

`asdg-low-mem_0.0.library` and `asdg-low-mem(10-jun-87).library` have
the same sha256 (`d9b6df26...`).  They are the same binary under two
file names — presumably both refer to the idstring date
`asdg low memory alert server (10-Jun-87)`.  There are no version
differences to document; the same reconstructed source is used for
both directories.
