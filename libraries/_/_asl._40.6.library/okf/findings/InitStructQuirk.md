# InitStruct offset quirk

The first InitStruct op is `INITBYTE(0x0c, 9)`.  The canonical form
used by freeanim_40.9 (and generated by NDK macros) is
`INITBYTE(0x08, 9)` for `ln_Type`.  Writing at 0x0c puts 9 into the
third byte of the `ln_Name` pointer — which is then completely
overwritten by the following `INITLONG(0x0a)`.  Net effect: ln_Type
is never set (stays 0) and the byte write is dead.  The same quirk
appears in fantasia_1.0.  Likely a code-generator bug in whatever
tool produced these images.
