# XpksPackerInfo

`lea` + `rts` — returns a pointer to the static XpkInfo
block embedded in the code hunk (see structures/descriptors).

Fields: ver words 1/1/2/0, name "ILZR", longname
"Incremental LZ-Renau V1.5", desc "A very fast low memory
compression, fast hash version of LZSS", id `ILZR`,
flags 9, MaxPkInChunk 0x4000, DefPkInChunk 0x4000, DefMode
100, single-node XpkMode (upto 100, packmem 0x18004,
desc "fast").
