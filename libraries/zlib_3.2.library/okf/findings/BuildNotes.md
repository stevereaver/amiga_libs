# Build notes

All 17 library `.c` units + `test.c` compile to objects under
m68k-amigaos-gcc 16.2 (bebbo fork):

```sh
m68k-amigaos-gcc -Os -m68020 -fbaserel -msmall-code -D__STORMGCC__ \
    -Wno-int-conversion -I. -Iinclude -Icompat -c <unit>.c
```

`source/compat/` holds shims for StormC headers (`clib/dos_protos.h`,
`clib/exec_protos.h`, `clib/asyncio_protos.h`, `clib/powerpc_protos.h`,
`libbase.h`); they are not original code.

Not reproducible here:

- PPC half (needs StormC PPC/WarpOS backend; sources are C but PPC codegen is
  StormC-specific — `__saveds`, `powerpc_protos.h`, `AllocVecPPC`).
- Final `.library` link — the resident/AUTOINIT init+exit scaffolding is
  generated by the StormC mixed-binary runtime (`libbase.h` `sLibBaseC`
  machinery opens `powerpc.library` v15 non-fatally).
- `test_ppc*.c` require `OpenAsyncPPC` from a PPC asyncio.library.
