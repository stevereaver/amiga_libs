# xpkLIN4 V1.1 (1 Oct 2013) by Gerhard Tuenkler

xpk sub-library implementing the Lino4 packer ("Improved version of
Lino2, best packing"). Single CODE hunk, AUTOINIT resident, 10
word-offset vectors exposing the standard xpk sublib interface
(PackerInfo/Pack/Unpack/mode table with minimal/normal/maximal
entries).

- `structures/layout.md` — hunk map, resident, InitTable, functab
- `functions/vectors.md` — LVO table
- `findings/defects.md` — quirks
