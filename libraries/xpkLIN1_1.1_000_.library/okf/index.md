# xpkLIN1.library 1.1 (1 Oct 2013, Gerhard Tuenkler)

XPK compression sublibrary ("Lino1", m68k 000 build).

10 word-offset vectors incl. 3 NULL holes.

- `functions/vectors.md` — LVO table + codec semantics
