# zlib_3.2.library — Reconstructed Source

Reconstruction of `binary/zlib_3.2.library`
(`$VER: zlib.library 3.2 (11-Apr-03)`, 106,984 bytes, Amiga loadseg hunk binary).

## Provenance

This is **Achim Stegemann's zlib.library 3.2** — the first Amiga shared zlib
library supporting both m68k and PowerPC (WarpOS) in one binary
(Aminet `util/libs/zlib-library.lha`, 2003-04-28). The shipped binary in this
repo is **byte-identical** to `Libs/zlib.library` inside that archive, and the
archive ships the complete StormC sources (`Developer/SRC/*`). The files here
are those sources, verified against the binary during reverse engineering.

- Author: Achim Stegemann (achim.stegemann@onlinehome.de)
- Core: **zlib 1.1.4** (Jean-loup Gailly / Mark Adler) — confirmed by embedded
  `deflate 1.1.4` / `inflate 1.1.4` copyright strings
- Toolchain: **StormC4 GCC** with `__MIXEDBINARY__` define (Storm Shell project
  files `zlib.ｶ` / `zlib_ppc.ｶ` are in the Aminet archive, not reproduced here)

## Binary layout (6 hunks)

| Hunk | Type | Bytes | Contents |
|------|------|-------|----------|
| 0 | CODE | 44,392 | m68k: RomTag, AUTOINIT, lib init/open/close/expunge, `GZ_*` entries (func.c), full m68k zlib (gzio/deflate/inflate/crc32/adler32/zutil), StormC runtime |
| 1 | CODE | 45,588 | **PPC**: `PPCGZ_*` entries (func_ppc.c) + full PPC zlib core |
| 2 | CODE | 472 | PPC helper routines (StormC mixed-binary glue) |
| 3 | DATA | 14,260 | data + function table + SAS/C-style near-data reloc table + strings |
| 4 | DATA | 508+44 bss | data incl. `_SysBase` ref + dispatch tables |
| 5 | BSS | 644 | — |

RomTag: `RTF_AUTOINIT`, `NT_LIBRARY`, pri 0, `lib_Version=3`, `lib_Revision=2`,
`dataSize=0x22` (plain `struct Library`, no private data — see
[okf/structures/ZLibBase.md](../okf/structures/ZLibBase.md)).

The `GZ_*` entry points are m68k and run a complete m68k build of zlib; the
`PPCGZ_*` entry points jump straight into PPC code in hunk 1 (WarpOS switches
CPU context when a PPC program calls through the library vector). See
[okf/](../okf/index.md) for per-function notes.

## Files

- `func.c` — 68k `GZ_*` wrappers over `gz*` (gzio) + memory deflate/inflate
- `func_ppc.c` — PPC `PPCGZ_*` equivalents (first arg = `struct Library *`)
- `libbase.c` — StormC `sLibBaseC` declaring `powerpc.library` base lib
- `zlib.h zconf.h zutil.h` + `adler32.c compress.c crc32.c deflate.c trees.c`
  `gzio.c infblock.c infcodes.c inffast.c inflate.c inftrees.c infutil.c`
  `uncompr.c zutil.c` — zlib 1.1.4 core, Amiga-adapted
  (`gzio.c` uses dos.library `Open/FRead/FWrite/Seek/Close` and
  `AllocVec`/`AllocVecPPC`; `zutil.h` maps `ZALLOC/ZFREE` to `AllocVec/AllocVec`)
- `zlib_lib.fd` — function descriptor (LVO layout above)
- `include/` — public developer headers shipped in the archive
  (`libraries/zlib.h`, `clib/zlib_protos.h`, `pragma/zlib_lib.h`, `zlib_lib.fd`)
- `test.c`, `test_ppc.c`, `test_ppc_ppc.c` — example programs shipped in the
  archive (not part of the library)
- `zlib.doc` — original autodoc
- `compat/` — **added by us** for build verification; NOT part of the original
  library (StormC `clib/*_protos.h` / `libbase.h` shims onto NDK headers)

## Build verification (this repo)

All units compile under the bebbo/AmigaPorts cross compiler:

```sh
m68k-amigaos-gcc -Os -m68020 -fbaserel -msmall-code \
    -D__STORMGCC__ -Wno-int-conversion \
    -I. -Iinclude -Icompat -c <unit>.c
```

Result: every `.c` compiles cleanly (`-Wno-int-conversion` is only needed for
`s->file = NULL` on a `BPTR` in `gzio.c` — see findings). The PPC half cannot
be rebuilt here (requires StormC/WarpOS toolchain), and re-linking the actual
`.library` requires the StormC mixed-binary runtime (resident init/expunge
scaffolding is generated by the StormC linker, not present in the sources).

## Known inconsistencies

See [okf/findings/](../okf/findings/index.md) — header return-type bugs, a
broken public macro, divergent 68k vs PPC clamp logic, `GZ_FileLength`
limitations, and FD public/private discrepancies.
