# mathieeedoubbas.library 45.3 (WB3.9)

Unlike the 40.x Berndt siblings (AUTOINIT, absolute-longword
functab, a private DELEXP byte), this is a COLDSTART module whose
rt_Init does the whole bootstrap itself: OpenResource("fpsp.resource"),
pick a functab, MakeLibrary(dataSize=0x40), fill private fields,
AddLibrary.  The same 16 LVOs (-6..-96) exist in all three flavours;
Cmp/Tst/Abs/Neg/Ceil share single integer bodies, while Fix/Flt/
Add/Sub/Mul/Div/Floor come in FPU and software variants (Floor has
a third variant that calls fpsp.resource vector -30).

## Binary facts

- sha256 `b3a09e8b69424b1b15d94e25537a8e889a0250213979def3bf39beec843b1150`, 3612 bytes
- single CODE hunk, 0xdcc bytes (0x373 longs)
- RELOC32: one group of 7 offsets in non-sorted order
  (`fc 7c 0a 1a 06 12 16`) — RomTag fields + datatab ln_Name +
  the `move.l a0,segcell` operand
- RomTag @4: `4afc`, MatchTag=4, EndSkip=0xdcc, flags=RTF_COLDSTART,
  version 45, NT_LIBRARY, pri 0
- name `mathieeedoubbas.library`; idstring
  `$VER: mathieeedoubbas.library 45.3 (23.11.2000)\r\n`
- entry point @0: `moveq #-1,d0; rts` (returns -1)
- functabs @0x184 (software), @0x1a8 (68881), @0x1cc (040/fpsp):
  0xffff marker word + 16 signed word offsets + 0xffff terminator

## Status

**BYTE-IDENTICAL** — verbatim `source/mathieeedoubbas_45.3_h0.s`
(all-literal .short image generated by `work/gen_source.py`, so gas
emits no relocs) + `source/fixup.py` splices the original header and
RELOC32 tail after asserting hunk-body equality.  `make` ends in
`cmp` against the shipped binary: md5 `9ca1dfb8c3bf809410a47b57eee5fddb`.

**RUNTIME-IDENTICAL** — `work/oracle.py` (machine68k, M68020) runs
the init functab-select matrix (fpsp x AttnFlags), open x2, all 16
vectors over edge inputs on each of the three functab flavours,
reserved -24, deferred + real expunge; line-F vector emulates the
68881 subset (fmove.d/l, fpcr moves incl. (sp)+/-(sp),
fadd/fsub/fmul/fdiv.d, fintrz.d, fint.x) and a fake fpsp.resource
-30 gate (d0=3 fintrz / d0=1 fint).  `orig.log` == `rebuild.log`
(diff clean).
