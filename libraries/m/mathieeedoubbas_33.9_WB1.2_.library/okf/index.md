# mathieeedoubbas.library 33.9 (WB1.2)

Workbench 1.2 double-precision IEEE basic math library.
Single CODE hunk + two empty hunks, plus a HUNK_SYMBOL debug
tail naming all internal routines (MIInit, MIIEEEDP*, dfi*,
DPAdd/Div/Cmp/Fix/Flt/Neg/Mul/Sub/Tst, _CXA55...).
AUTOINIT resident@h0+0 ver 33, word-offset functab.

- `structures/layout.md` — hunk map, resident, InitTable
- `functions/vectors.md` — LVO table
- `findings/defects.md` — quirks
