# rexxidentify.library 1.15 (13.02.2022)

ARexx command interface for Richard 'Shred' Koerber's
identify.library (LGPL v3). Registers an ARexx function host with
commands like ID_RELEASE/ID_NUMBOARDS/ID_HARDWARE plus the
MANUF/CLASS/SYSTEM/OSVER/EXECVER/CHIPSET/POWERPC/... query set.

- `structures/layout.md` — hunk map, resident, InitTable, datatab
- `functions/vectors.md` — LVO table
- `findings/defects.md` — quirks
